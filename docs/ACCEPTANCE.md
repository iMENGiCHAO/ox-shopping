## 4. 配置说明（对应文档 §6.4 / Shopify 能力的等价物）

### 多货币
- 页头货币选择器：CNY ¥ / USD $ / EUR € 等，客户端按汇率即时换算展示；
- 订单仍以人民币本位记账（`Order.totalCny`），汇率表见 `src/lib/currency.ts`。

### 支付
- 开发环境：mock 支付通道（一键模拟成功），用于全流程联调；
- 生产：Stripe 卡支付已接入（`STRIPE_SECRET_KEY` 环境变量），Apple Pay/微信/支付宝需在
  对应渠道开户后按 `src/app/api/payments/` 现有适配器扩展。

### 库存
- 下单事务内 `stock >= qty` 条件更新，杜绝超卖；
- 管理端商品表单可实时改库存；库存流水见审计日志。

### 预售
- 商品表单「预售商品」开关（`Product.isPresale`）；
- 行为：0 库存可加购/下单（上限 5 件）、扣减时库存下限钳制为 0、前台显示「预售」标签
  与「付款后 14 天内发货」提示。

### 站点内容（后台直达前台）
- 「站点设置」：站名、SEO 关键词、联系方式、ICP、**全站公告栏**开关与文案；
- 分类图片 = 首页横幅 & 集合页 hero；商品图/规格 = 前台详情。

## 5. 已知限制与后续优化点

1. **变体引擎为简化版**：规格（颜色/容量等）作为属性标签随行项目保存，未做"矩阵 SKU"
   （切换颜色不会联动换价/换图）。x.com 的深度变体需要 SKU 级拆分，属二期重构项。
2. **多货币为展示层换算**，非 Shopify Markets 式分区定价/分区运费；如需分国家定价，
   需引入价格簿模型。
3. **邮件通知依赖 SMTP 配置**：未配置时验证邮件/重置链接仅记录于服务端日志（注册/改邮箱
   流程不受阻）。
4. **素材版权**：当前使用 shop.x.com 摄影图仅为开发期视觉对齐（客户明确要求）；上线前必须替换为自有授权素材，否则存在侵权风险。
5. **性能**：首页已做懒加载与流式渲染；后续可加 ISR 化商品页与 CDN 边缘缓存。
6. **i18n**：站点已锁定纯中文运营（语言切换已移除）；字典机制保留，未来恢复多语言成本低。
