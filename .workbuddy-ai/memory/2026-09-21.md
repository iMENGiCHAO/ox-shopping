## 分销规则页样式修复（大爷反馈「作用域 / ID / 层级 栏叠在一起」）

### 根因：`table-fixed` 下「没定宽的那一列」会被压成 0

`src/app/admin/distribution/rules/page.tsx` 的佣金规则表 8 列里，7 列写了 `w-[..]`（合计 890px），
只有「作用域 ID」是 `min-w-0` 没定宽 ⇒ 它成了"被挤压的那一列"。
Table 组件（`components/ui/table.tsx`）是 `w-full table-fixed` + 外层 `overflow-x-auto`，
**`w-full` 覆盖了 `min-w` 的滚动语义** —— 容器窄于 890 时不会滚动，而是把这列压到 0 宽，
单元格内容竖排成单字并压到「层级」列上。

**登录后实测**（管理员 `admin@example.com` / `Admin@123456`，见 `prisma/seed.ts:20`）：

| 视口 | 后台内容区 | 「作用域 ID」列宽 | 内容宽 |
| --- | --- | --- | --- |
| 1600 | 1230 | 340 | 340 ✓ |
| 1440 | 1070 | 180 | 180 ✓ |
| 1280 | 910 | **20** | 41 ✗ |
| 1024 | 654 | **0** | 41 ✗ |
| 768 | 678 | **0** | 33 ✗ |

### 修法：每列都定宽 + 把宽度之和写进 `min-w` + 窄屏渐进披露

- `Table className="min-w-[620px] xl:min-w-[892px]"`
- 列宽：作用域 88 / 作用域 ID 160 / 层级 64 / 佣金口径 130 / 生效期 144 / 启用 72 /
  更新时间 140 / 操作 96（sticky right）
- **生效期与更新时间 `hidden xl:table-cell`** —— 分档依据是**后台内容区实测宽度**
  （654@1024 / 910@1280 / 1070@1440 / 1230@1600），不是视口断点：
  核心 6 列 620 在 1024 的 654 里放得下；补上两列后 892，1280 的 910 也放得下
  ⇒ 两列统一 `xl`(1280) 起显示。
- 骨架行要同步隐藏（新增 `COL_HIDE` 常量），否则加载态会出现「表头没有该列、单元格却有骨架条」。
- ⚠️ **`truncate` 对 inline 元素无效**：原来是 `<span className="truncate">`，必须加 `block`
  才真的截断成省略号（否则长 ID 直接溢出到相邻列）。

### 附带发现

- `tailwind.config.ts` 把 **`2xl` 改成了 1600px**（不是默认的 1536），算分档时别按默认值推。
- 「层级」列 56px 时表头被截成「层...」：`md:p-4` 吃 32px，56−32=24 < "层级" 的 28 ⇒ 给到 64。

## 商品描述段落结构回填（P0，数据问题）

### 根因

`prisma/xcom-catalog.ts` 的 `description` 是从官方 `/products.json` 的 `body_html` 生成的，
**生成时剥 `<p>` 标签把段落分隔一起丢了** ⇒ 32 条描述**全部**是一整块长文本（无 `\n`）。
而 PDP 的 `.desc-prose` 明明按空行切段（`split(/\n\s*\n|\n/)`）—— 逻辑没问题，是数据没有分隔符。

### 取证与回填

- 原站段落结构来源：`WebFetch https://shop.x.com/products.json?limit=250`，
  **不要让它吐全文**（97,906 字符会被模型总结成 190KB 分析且 JSON 截断、无法 parse）。
  改成要求「每个商品一行：`handle :: 每段前 25 字`」⇒ 一次拿到 23 个商品的段落前缀 ✓
- 本地文案里 `indexOf(前缀)` 定位断点：**24/24 全部命中**（`/tmp/para-prefixes.json`）
- 写回 catalog（插入转义的 `\n\n`，因为 TS 双引号串不能有真实换行），备份 `xcom-catalog.ts.bak-paras`
- **DB 回填脚本**：`scripts/backfill-descriptions.ts` + `npm run db:backfill-descriptions`
  （`--apply` 才写库）。为什么必须单独写：`prisma/seed.ts` 用 `upsert({ update: {} })`
  —— 幂等、不覆盖已有行，**重跑 seed 不会更新线上已有商品**。
- 结果：23 条已更新，复跑 0 条（幂等 ✓）

⚠️ 原站当前目录只有 **25 件**，本地多出的 6 件（`hardcore-grok-reflective-tee`、
`grok-logo-tee-copy`、`xai-vessel`、`unisex-3d-logo-dad-hat`、
`macrohard-remove-before-flight-keychain`、`x-the-everything-mug`）原站已下架 ⇒ 无源可取，保持单段。
